# KardexRead

KardexRead es una **aplicación de escritorio para Windows** desarrollada en **C# con Windows Forms (.NET)**.  
Su objetivo es **leer un archivo Kardex en formato PDF** y **convertir la información relevante a un archivo Excel (.xlsx)**, facilitando el análisis y manipulación de los datos.

---

## Tipo de aplicación

- Aplicación de escritorio (Windows Forms)
- Desarrollo en Visual Studio
- Enfoque en automatización y procesamiento de datos

---

## Funcionalidad principal

- Carga de archivos Kardex en formato PDF
- Lectura y extracción de datos desde el PDF
- Conversión de la información a formato **Excel (.xlsx)**
- Generación de archivos compatibles con Microsoft Excel

---

## Tecnologías utilizadas

- C#
- .NET
- Windows Forms
- Visual Studio

---

## Librerías utilizadas

- **iText**  
  Utilizada para la lectura y extracción de información desde archivos `.pdf`.

- **EPPlus**  
  Empleada para la creación y manipulación de archivos Excel en formato `.xlsx`.
